# 霧ノ森 蝋人形館さんぽ

霧の立ちこめる森の奥の古い屋敷を、スマホで歩いて巡る3D散策ホラー。
お城さんぽシリーズと同じ操作系（three.js r128・単一HTML）。

- 公開ページ: https://32miya.github.io/wax-museum-sanpo/
- 森・前庭・墓地・枯れ井戸 → 館（1階・2階・地下の11部屋）
- 「あの夜」⇄「現在（廃墟）」の切り替え、宵／丑三つ時、霧の濃さ
- 見どころ札集め（歩いて訪れたときだけ）、写真モード、合成音（風・オルガン・叫び声）
- メニューの「物語」で言い伝えを読めます

屋敷と物語は架空のものです。流血などの怖い表現があります。

## 霧ノ森の鬼ごっこ（oni.html）

- 公開ページ: https://32miya.github.io/wax-museum-sanpo/oni.html
- 2〜8人でオンライン対戦（部屋をつくる → 4桁の部屋番号を仲間に伝える → 部屋に入る）。ひとりでもAIの鬼と遊べます
- 役割：逃げる側（迷い人4種）／鬼（悪魔6体）。鬼がいないときはAIの鬼が出ます
- 視点：いつもは自分の背中が見える三人称、隠れているときは一人称
- 隠れ場所15か所
- 鬼は最低2体（人が鬼をやる人数が足りない分はAIの鬼で補う）。1体目は館の中、2体目は森からスタートし、以降も館と森に交互に配置。森の鬼は獣道を中心に見回る
- 館の鬼のうち1体は、鬼が動き出すと森の小道を入口の方へ半分まで見回りに来て、館へ戻っていく
- 逃げる側は森の入口から出発。館のどこかにある「銀の鍵」を拾い、北の「森の出口」までたどり着けば脱出（ひとりでも脱出すれば逃げ側の勝ち）。鬼は全員を捕まえれば勝ち（時間切れで誰も脱出していなければ鬼の勝ち）
- 鬼の移動速度は1.2倍。捕まると蝋人形になり鍵は元の場所に戻る。仲間のそばで「助ける」を3秒長押しすると復活（手を離すと0から）
- 隠れている間は絶対に捕まらない
- 見つかった合図：鬼に追われている間は画面のふちが赤く脈打ち「見つかった！逃げろ」、近くで探されている間は黄色く「近くで探している……」（隠れていても、そばで待ち伏せされていると黄色）
- しゃがむ（ボタン／Cキー）：遅くなり走れないが、木箱・樽・長椅子・倒木・岩・茂みなど低い物の陰に体が隠れる。鬼の視線が切れたら物陰でしゃがんで見失わせよう（2.5m以内まで近づかれると見つかる。屋外の霧の中では7m以上離れればしゃがむだけで見えない）
- 通信：PeerJS（WebRTC の P2P、無料公開サーバー 0.peerjs.com で仲立ち）。部屋を作った人の端末が判定・AIを計算するので、主はアプリを前面に出したままにしてください
- 通信が切れたとき：自動でつなぎ直し、同じ席・同じ状態で続きから遊べます（試合中は3分、控え室は90秒まで席を取っておきます）。ページを閉じてしまっても、20分以内ならタイトルの「前の部屋に戻る」で戻れます。主（部屋を作った人）がページを閉じると部屋は終わります
- 鬼の役割表: demons.html
