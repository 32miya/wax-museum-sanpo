# 霧ノ森 蝋人形館さんぽ

霧の立ちこめる森の奥の古い屋敷を、スマホで歩いて巡る3D散策ホラー。
お城さんぽシリーズと同じ操作系（three.js r128・単一HTML）。

- 公開ページ: https://32miya.github.io/wax-museum-sanpo/
- 森・前庭・墓地・枯れ井戸 → 館（1階・2階・地下の11部屋）
- 「あの夜」⇄「現在（廃墟）」の切り替え、宵／丑三つ時、霧の濃さ
- 見どころ札集め（歩いて訪れたときだけ）、写真モード、合成音（風・オルガン・叫び声）
- メニューの「物語」で言い伝えを読めます

屋敷と物語は架空のものです。流血などの怖い表現があります。
